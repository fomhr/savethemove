# savethemove

세이브더칠드런 직원 연수 초대용 반응형 웹페이지입니다.

## 실행

별도 빌드 없이 `index.html`을 열거나 로컬 서버를 실행하면 됩니다.

```bash
python3 -m http.server 4173
```

## 주요 기능

- 봉투형 초대장 오프닝 애니메이션
- 행사개요, 전체일정, 편성조 안내 페이지 전환
- 확정된 212명 편성조 이름 검색(동명이인 구분) 및 A~D조 전체 명단 조회
- 모바일 반응형 및 모션 감소 설정 지원

## 편성 명단 관리

- `team-data.js`: 2026-10-23 확정 편성(212명)에서 **조·조내 순서·이름·영역·기관명**만 가져온 공개 사이트용 데이터입니다.
- 사번, 연차, 직급 및 이동수단은 게시하지 않습니다.
- 명단을 변경할 때는 행사 운영용 구글시트의 `전체배정`을 기준으로 `team-data.js`를 함께 갱신하세요.
- GitHub Pages 사이트는 **공개**되어 있어 조별 명단을 링크 방문자 누구나 조회할 수 있습니다.
